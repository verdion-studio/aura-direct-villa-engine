# Working Rules - Prosedur Kerja Veridion Studio

## Siklus Pengerjaan Standar (Step-by-Step SOP)
1. **Rancang (Design & Architect):**
   - Menentukan arsitektur data, komponen, dan spesifikasi fungsional sebelum coding.
   - Mengikuti panduan modularitas dan single responsibility.
2. **Konfirmasi (Checkpoint Alignment):**
   - Mengkomunikasikan rencana dan hasil tahapan secara transparan kepada user di setiap checkpoint.
3. **Eksekusi (Execution):**
   - Implementasi komponen secara rapi, bersih, dan sesuai kaidah project rules.
   - Dokumentasi kode yang memadai dan self-explanatory.
4. **Validasi Build (Build & Quality Audit):**
   - Menjalankan `npm run build` atau Astro check untuk menjamin nol error sintaks dan bundle bersih.
   - Memastikan tidak ada layout break atau styling yang tidak ter-render.
5. **Commit & Delivery:**
   - Menyimpan progres dengan pesan commit terstruktur (`feat:`, `fix:`, `chore:`, dsb.).
   - Menyiapkan ringkasan instruksi operasional untuk peninjauan user.

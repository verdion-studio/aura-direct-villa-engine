# Web Evaluation & Audit Standards

## Kriteria Evaluasi
1. **Lighthouse & Core Web Vitals:**
   - Performance: Target 90+
   - Accessibility: Kontras warna teks mewah terhadap background gelap/terang memenuhi standar WCAG AA.
   - Best Practices: Zero console errors, HTTPS ready, rel="noopener" pada external links.
   - SEO: Title tag, meta description, structured data JSON-LD (`LodgingBusiness` / `Hotel`).
2. **Mobile Responsiveness Audit:**
   - Viewport 375px (iPhone SE/Mini) hingga 430px (Pro Max): sticky CTA bar atau floating booking trigger tidak boleh menutupi konten penting.
   - Sentuhan jari nyaman: touch target minimal 44x44px.
3. **Conversion Funnel Integrity:**
   - Date selection -> Price computation -> Payment selection -> QRIS modal -> WhatsApp preview.
   - Pastikan alur dapat diselesaikan dalam kurang dari 30 detik tanpa lag.
